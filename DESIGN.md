# Creative Vertices Design System (DESIGN.md)

## Brand Identity & Direction
- **Product**: Creative Vertices, a code-driven digital template storefront powered by Astro v7, Tailwind CSS v4, and EmDash CMS.
- **Audience**: Frontend engineers, design technologists, independent studios, and SaaS founders who evaluate templates by source architecture, DOM weight, and typographic rigor.
- **Visual Language**: Cloudflare technical minimalism merged with GetAstroThemes navigation, JustStart.now catalog filtering, and XocoThemes conversion structure.
- **Dial**: `ENERGY 2 / RHYTHM 3 / MOTION 2`

## Color Palette (2 Core Neutrals + 1 Deliberate Accent)
- **Dark Surface (Default)**: `#0A0B0E` primary canvas (`--cv-bg` / `--color-canvas`), `#111318` elevated panel surface, `#181B22` interactive hover surface, `#F5F6F8` stark primary text (18.9:1 on `#0A0B0E`), `#A3AAB8` (`--color-gray-400`, 8.43:1 on `#0A0B0E`), `#8B93A4` (`--color-gray-500`, 6.38:1 on `#0A0B0E`), `#222631` (`--color-gray-800`, 1px structural card border).
- **Light Surface (Theme Toggle)**: `#F7F6F2` warm technical paper canvas (`--cv-bg` / `--color-canvas`), `#EFECE6` panel surface, `#0E1015` ink primary text (17.5:1 on `#F7F6F2`), `#454B57` (`--color-gray-400`, 8.10:1 on `#F7F6F2`), `#525866` (`--color-gray-500`, 6.59:1 on `#F7F6F2`), `#D8D4CA` (`--color-gray-800`, 1px structural card border).
- **Signature Vibrant Accent**: `#FF5500` (International Signal Orange, `--color-orange-500`) in dark mode (5.12:1 against `#0A0B0E` for large/UI graphics, `#FF6A1A` 5.95:1 on `#0A0B0E` for accent text, `#0A0B0E` text on `#FF6A1A` solid buttons at 6.87:1) and `#B83700` in light mode (`#FFFFFF` text at 5.86:1).

## Typography
- **Geometric Sans-Serif**: `'Plus Jakarta Sans', 'Helvetica Neue', Arial, sans-serif` (self-hosted system-safe stack with geometric proportions for crisp technical headlines and dense UI metadata).
- **Tabular / Technical Monospace**: `'JetBrains Mono', ui-monospace, 'SFMono-Regular', Menlo, monospace` (strictly for template counts, prices, page counts, schema keys, and version identifiers).

## One-Line Purpose Record (R-31)
- **Color Palette**: High-contrast charcoal/white with a single signal-orange vertex accent focuses visual attention on interactive coordinates, active filter states, and primary checkout actions without decorative gradients.
- **Continuous Dashed Container Borders**: Vertical dashed structural rails (`border-l border-r border-dashed`) establish a continuous blueprint coordinate frame that binds the header, storefront split-grid, and conversion sections into one unified architectural column.
- **Four-Corner Canvas-Masked Registration Marks on Cards**: Every template card, "Why Creative Vertices" feature card, "All-Access Bundle" promotional card, FAQ accordion card, and state panel uses a continuous 1px border (`border border-gray-800`) anchored by four 1px-stroked corner squares filled with the solid main page background (`bg-[var(--cv-bg)] border border-orange-500` at `top-0 left-0 -mt-1 -ml-1`, `top-0 right-0 -mt-1 -mr-1`, `bottom-0 left-0 -mb-1 -ml-1`, and `bottom-0 right-0 -mb-1 -mr-1`) so each square masks out the underlying gray card border at the exact point of intersection.
- **Minimal Two-Group Sticky Glassmorphism Navbar (Dose = 1, R-04, R-10, R-15)**: `backdrop-blur-md` is applied exclusively to `NavBar.astro`, pairing only the left-aligned "Creative Vertices" wordmark with a right-aligned actions container (a square-stroked Sun/Moon SVG theme toggle icon and the sharp signal-orange "All Access" primary conversion CTA) to reduce cognitive load.
- **Single-Column Typography Hero & Monospace Metadata Row (R-05, R-06)**: Constraining the hero to a single `max-w-4xl` left-aligned column eliminates competing hero buttons (delegating conversion to the sticky navbar `All Access` CTA), while the `font-mono text-xs uppercase tracking-widest` mid-dot metadata row anchors the headline with verified stack specs (`ASTRO v7.4 · TAILWIND v4.3 · EMDASH CMS v3.8 · 0 EXTERNAL REQUESTS`).
- **25% / 75% Template Archive Split & Mixed 2-Col / 3-Col Grid (R-05, R-06, R-14)**: Under "The Template Archive" header, the left 25% rail presents the 13-sector "BROWSE BY SECTOR OR SITE TYPE" filter list with right-aligned tabular monospace counts (`tabular-nums`) and a 2px left signal-orange active indicator (`border-l-2 border-[var(--cv-accent)]`), top-aligned (`p-4 sm:p-6 lg:p-8`) with the 75% main grid where flagship featured templates span 2 columns above 3-column catalog rows.
- **Whole-Card Clickable Template Cards with 16:9 Previews & Single-Line Truncated Footer (R-14, R-26, R-40)**: Wrapping each `<article>` in a full-card `<a>` link with `aspect-video` (16:9) previews, compact `px-4` padding, a single right-aligned style tag (`LOUD`, `INDEX`, etc.), and a `truncate` typeface row eliminates button clutter and prevents text wrapping in narrower 3-column cards.
- **Asymmetric Section Rhythm (RHYTHM 3)**: Sections progress from a single-column typographic hero, to a 25/75 interactive template archive, to an asymmetric 4-column architectural proof matrix, to a full-width high-contrast bundle schematic banner, and finally a 2-column split FAQ accordion.
- **Snappy Hover & Height Transitions (MOTION 2)**: Card hover transforms (`-translate-y-0.5` and corner registration border contrast) provide immediate spatial feedback on selectable items, while the `<cv-faq>` custom element animates accordion height cleanly and respects `prefers-reduced-motion`.
